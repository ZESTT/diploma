  • useState: Local state.
  • useEffect: Side effects.
  • Events: onClick, onChange.

  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>
    Count: {count}</button>;
}

Express.js

  • Framework: Minimal Node.js.
  • Routing: GET, POST, PUT, DELETE.
  • Middleware: Pre-handler functions.
server.js
const express = require('express');
const app = express();
app.get('/api/data', (req, res) => {
  res.json([{ id: 1, name: 'John' }]);
});
app.listen(5000);

MongoDB & Mongoose

  • NoSQL: JSON-like documents.
  • Mongoose: ODM for Node.js.
  • CRUD: Create, Read, Update, Delete.
models/User.js
const mongoose = require('mongoose');
const userSchema = new mongoose.Schema({
  name: String,
  email: String
});
module.exports = mongoose.model('User', userSchema);

Full Stack Workflow

1. User submits form in React
⬇
2. React sends POST to Express
⬇
3. Express saves to MongoDB
⬇
4. MongoDB returns document
⬇
5. Express sends JSON to React
⬇
6. React updates UI

Authentication: JWT & Bcrypt

  • Bcrypt: Hash passwords.
  • JWT: Secure user identity.
  • Protected Routes: Token required.
auth.js
const token = jwt.sign(
  { userId: user._id },
  process.env.JWT_SECRET,
  { expiresIn: '1h' }
);
